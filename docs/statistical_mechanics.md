# Statistical Mechanics of Black-Hole Entropy

## Ensembles

For a finite spectrum $\{E_i\}$ the canonical partition function $Z=\sum_ie^{-\beta E_i}$ gives $C = \beta^2\,\mathrm{Var}(E)\ge0$. The two-level system reproduces the Schottky heat capacity to $3\times10^{-15}$ (Fig 14).

For a gravitating density of states $S(E)=4\pi E^2$ (Planck units) the canonical saddle $\beta=dS/dE=8\pi E$ is a *minimum* of $S-\beta E$: the canonical ensemble is ill-defined and the microcanonical description must be used. This is the statistical origin of $C<0$.

## State counting

The Bekenstein-Hawking entropy implies an effective microstate count $\ln\Omega=A/4$; for one solar mass $\log_{10}\Omega_{eff}\approx4.6\times10^{76}$. This is an *inference from the entropy formula*, not an enumeration of states.

## Corrections

$S=A/4+\alpha\ln A$: the fitted slope of $S-A/4$ against $\ln A$ recovers the input $\alpha$ (Fig 12), demonstrating the fitting procedure only. The sign and size of $\alpha$ are model-dependent and unconstrained by this code.

## Scaling

Entropy of an ordinary gas scales with volume, black-hole entropy with area. Equating them at $300$ K gives a crossover radius $1.5\times10^{54}$ m, far beyond the observable universe, which is only an illustration of the scaling (Fig 13).
